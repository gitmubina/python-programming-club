DATA TYPES
What are data types?
A data type tells Python what kind of information a value is, and what it can do with it.
# numbers get added
5 + 5
10
# text gets glued together
"5" + "5"
"55"
Same symbols, different answers
The quotes change the type, so Python treats them differently.

VARIABLES
What are variables?
A variable is a name that stores a value, like a labeled box you can open later.
name
"Maya"
name = "Maya"
age
12
age = 12
game_over
False
game_over = False
=
In Python, = means "put this value in the box." It does not mean "equals" like in math.

VARIABLES
How do we use variables?
1 · CREATE
score = 0
Makes the box and puts 0 in it.
2 · USE
print(score)
Looks inside the box. Shows 0.
3 · UPDATE
score = score + 10
Replaces the old value. Now it's 10.
Good names
player_name high_score lives2
Letters, numbers and underscores. Describe what's inside.
Not allowed
2lives starts with a number my score has a space high-score has a dash
Also: capitals matter. Score and score are different boxes.

VARIABLES
How variables work together
# numbers: do math
price = 3
quantity = 4
total = price * quantity
print(total)
12
# strings: glue together
first = "Ada"
last = "Lovelace"
full = first + " " + last
print(full)
Ada Lovelace
Careful: mixing types
Python won't add text and a number.
"Age: " + 12  →  TypeError
"Age: " + str(12)  →  Age: 12

ARITHMETIC OPERATORS
How do we use operators?
Order matters
Python follows math rules: * and / before + and -.
2 + 3 * 4 → 14
(2 + 3) * 4 → 20
Division makes floats
/ always gives a decimal. Use // for a whole number.
10 / 2 → 5.0
10 // 2 → 5
Update shortcuts
A quicker way to change a variable's value.
score += 5
# same as score = score + 5
Works on text too
+ glues strings. * repeats them.
"ha" * 3
→ "hahaha"
PEMDAS
Parentheses, Exponents, Multiply and Divide, then Add and Subtract. When in doubt, add parentheses.
